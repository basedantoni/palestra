# Card Fund is derived from finance, with rollover on the TCG side

TCG spending is not logged in TCG. The Card Fund is the Cards category's monthly finance budgets summed since a start month, minus that category's Budgeted Spend over the same months. A reader will expect card purchases to be totalled from Copy prices; they are not, because the $50/month covers shipping, tax, and supplies that are never Copies, and the money already arrives through bank transactions, so a TCG ledger would be double entry. Unspent budget carries forward in the Card Fund (so the user can save toward one expensive Printing) while finance budgets keep their no-rollover rule; changing finance for every category was rejected. A month with no Cards budget contributes nothing, so the TCG page flags missing months rather than silently shrinking the fund. Copy prices still exist, as what a card cost, not as budget input. Card charges must categorize as Cards via a Category Rule for the fund to be right.
