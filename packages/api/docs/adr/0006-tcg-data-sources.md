# TCG catalog from punk-records, artists from Limitless, prices by hand

> Superseded on prices and exchange rates by [0007](./0007-market-watch-price-sources.md). The catalog, artist and image parts stand.

As of October 2026 no sanctioned price feed exists for Japanese One Piece singles: TCGplayer has stopped granting API access and carries no Japanese One Piece, Cardmarket is not accepting API applications, and Japanese shops (Yuyu-tei, Card Rush) and Mercari have no API, with Yuyu-tei's terms forbidding reproduction. So Offers are entered by hand in USD for both languages; do not add a price sync without re-checking these. TCGCSV's free mirror of TCGplayer prices covers English only and gives a market average rather than a seller's delivered price, so it was declined as a reference. Bandai's card lists do not credit illustrators, so the Japanese and English catalogs are imported from punk-records (a static mirror of Bandai's lists, keyed by Bandai's variant ID such as `OP05-069_p1`) and artists are backfilled once per set from Limitless One Piece, the only source crediting artists per variant; an Artwork Limitless leaves uncredited stays blank. One variant ID is treated as one Artwork across both languages. That is assumed, not verified for every card, so the import flags any variant ID whose languages disagree on artist instead of merging silently. Card images stay on Bandai's servers and are never copied.

## Amended (October 2026, after KOI-304 shipped)

- **Images are relayed, not hotlinked.** Bandai sends `Cross-Origin-Resource-Policy: same-site`, so browsers refuse its images on our pages. The server relays them through `GET /api/tcg/image`. The route is signed-in only and fetches only Bandai card-image URLs. It refuses redirects, times out after 10 s and stores nothing; responses carry a 7-day private cache header.
- **The one-variant-ID-one-Artwork assumption fails for some reprints.** Bandai's Japanese and English lists can number the same print differently: OP05-119's PRB-01 print is `_p3` in Japanese and `_p4` in English. Limitless numbers its Japanese and English pages the same way, so both languages report the same artist and the conflict flag stays off. Those Japanese Printings can show another Artwork's artist. Japanese reprint IDs (`_rN`) never appear on Limitless and stay uncredited.
