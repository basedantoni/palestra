# TCG catalog from punk-records, artists from Limitless, prices by hand

As of October 2026 no sanctioned price feed exists for Japanese One Piece singles: TCGplayer has stopped granting API access and carries no Japanese One Piece, Cardmarket is not accepting API applications, and Japanese shops (Yuyu-tei, Card Rush) and Mercari have no API, with Yuyu-tei's terms forbidding reproduction. So Offers are entered by hand in USD for both languages; do not add a price sync without re-checking these. TCGCSV's free mirror of TCGplayer prices covers English only and gives a market average rather than a seller's delivered price, so it was declined as a reference. Bandai's card lists do not credit illustrators, so the Japanese and English catalogs are imported from punk-records (a static mirror of Bandai's lists, keyed by Bandai's variant ID such as `OP05-069_p1`) and artists are backfilled once per set from Limitless One Piece, the only source crediting artists per variant; an Artwork Limitless leaves uncredited stays blank. One variant ID is treated as one Artwork across both languages. That is assumed, not verified for every card, so the import flags any variant ID whose languages disagree on artist instead of merging silently. Card images are hotlinked from Bandai, not copied.
