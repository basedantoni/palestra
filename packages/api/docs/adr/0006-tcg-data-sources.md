# TCG catalog from punk-records, artists from Limitless, prices by hand

As of October 2026 no sanctioned price feed exists for Japanese One Piece singles: TCGplayer has stopped granting API access and carries no Japanese One Piece, Cardmarket is not accepting API applications, and Japanese shops (Yuyu-tei, Card Rush) and Mercari have no API, with Yuyu-tei's terms forbidding reproduction. So Offers are entered by hand in USD; do not add a price sync without re-checking these. Bandai's card lists do not credit illustrators, so the catalog of Printings is imported from punk-records (a static mirror of Bandai's Japanese list, keyed by Bandai's variant ID such as `OP05-069_p1`) and artists are backfilled once per set from Limitless One Piece, the only source crediting artists per variant; a Printing Limitless leaves uncredited stays blank. Card images are hotlinked from Bandai, not copied. Only the Japanese catalog is imported; English is the same import on another file.
